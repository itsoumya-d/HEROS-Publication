# GraphRAG-CodeAudit 100 Sensemaking Questions

100 deterministic questions over the synthetic sample repository used by
[GraphRAG-CodeAudit](https://github.com/itsoumya-d/GraphRAG-CodeAudit).
Questions cover security risks, dependencies, component review, and entity
interactions.

Fields: `id`, `question`.

Paper page: [From Local to Global: A Graph RAG Approach](https://huggingface.co/papers/2404.16130)

This is a synthetic harness dataset, not an enterprise corpus or the paper's
evaluation set.
