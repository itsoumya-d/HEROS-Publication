# HEROS-RL Destructive DDL Migration Set

500 deterministic prompts for training a critic-free GRPO policy to rewrite
hazardous PostgreSQL changes as expand-and-contract migrations.

- 10 families × 50 cases.
- 150 data-loss cases, 300 requiring expand-and-contract.
- 150 SAFE, 50 NOTABLE, 200 HIGH, 100 CRITICAL.
- Fields: `id`, `hazard`, `data_loss`, `requires_expand_contract`,
  `expected_tier`, `old_schema`, `target_schema`, `prompt`.

Paper pages: [DeepSeekMath](https://huggingface.co/papers/2402.03300) ·
[DeepSeek-R1](https://huggingface.co/papers/2501.12948)

Generated by `scripts/build_dataset.py` in
[HEROS-RL](https://github.com/itsoumya-d/HEROS-RL) and reproduced byte-for-byte
in CI.
