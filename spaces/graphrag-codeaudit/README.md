# GraphRAG CodeAudit Explorer

Local entity-neighbourhood search and global community-report search over a
synthetic repository. Built on
[GraphRAG-CodeAudit](https://github.com/itsoumya-d/GraphRAG-CodeAudit).

Paper page: [From Local to Global: A Graph RAG Approach](https://huggingface.co/papers/2404.16130)

The deterministic judge and sample repository are used; this is not the paper's
LLM-as-a-judge replication.
