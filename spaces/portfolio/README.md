# HEROS AI Systems Portfolio

Live index for the HEROS/edgeinfer systems: agent runtime and firewall, GRPO
migration rewards, Reflexion code repair, GraphRAG code audit, NEON kernel
optimization, Matryoshka retrieval, post-quantum P2P transport, calibrated model
routing, and PLLB governance.

Every project links to public source, CI, and measured local evidence. Three
interactive/static demos and two datasets are hosted on Hugging Face. Model
training runs that require unavailable GPU/provider credentials are labelled as
pending, not claimed.
