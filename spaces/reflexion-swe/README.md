# Reflexion-SWE Repair Loop

Interactive actor / evaluator / self-reflection loop on deterministic repair
fixtures. The evaluator generates tests, the sandbox executes them, and failures
become a verbal lesson in a 3-slot episodic memory.

Paper pages: [Reflexion](https://huggingface.co/papers/2303.11366) ·
[Training-Free GRPO](https://huggingface.co/papers/2510.08191) ·
[SWE-bench](https://huggingface.co/papers/2310.06770)

This Space demonstrates the harness, not HumanEval Rust or SWE-bench model
results. The full project is [Reflexion-SWE](https://github.com/itsoumya-d/Reflexion-SWE).
